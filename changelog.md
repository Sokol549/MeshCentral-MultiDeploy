# Changelog

## [1.0.0] - 2026-10-28
### Added
- Первоначальный релиз плагина **Multi-Device File Deployer** (`multideploy`) для MeshCentral.
- Поддержка параллельной отправки файлов на неограниченное количество компьютеров.
- Выбор целевых компьютеров по группам устройств (Mesh) или индивидуально с удобной фильтрацией.
- Фильтры «Только в сети» и поиск по имени/IP/ОС.
- Drag-and-Drop загрузка файлов в веб-интерфейсе с chunked-передачей на сервер без ограничений по размеру.
- Отслеживание прогресса в реальном времени (процент передачи, скорость в КБ/с и МБ/с, байты, оставшееся время).
- Сводная статистика (Всего, В процессе, Успешно, Ошибки).
- Возможность автоматического запуска файла после загрузки с настраиваемыми аргументами (`/quiet`, `--silent` и др.).
- Обработка ошибок и таймаутов, автоматическое создание целевых каталогов (`mkdir -p` / `New-Item`).
- Кнопка повтора для компьютеров, завершившихся с ошибкой или находившихся не в сети.
- Вкладка истории отправок с сохранением результатов в JSON.
- Интеграция кнопки в верхнюю панель управления MeshCentral и отдельная вкладка в свойствах устройства.
