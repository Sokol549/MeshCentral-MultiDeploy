# Multi-Device File Deployer Plugin for MeshCentral

**Multi-Device File Deployer (`multideploy`)** — это полнофункциональный плагин для [MeshCentral](https://meshcentral.com/), позволяющий администраторам отправлять файлы одновременно на несколько удалённых компьютеров с удобным графическим интерфейсом и отслеживанием прогресса передачи в реальном времени.

---

## 🌟 Основные возможности

- **Параллельная отправка**: Передача файла сразу на десятки или сотни компьютеров (Windows, Linux, macOS).
- **Выбор целевых устройств**:
  - Выбор всей группы устройств (Mesh) или произвольного списка компьютеров с помощью чекбоксов.
  - Умная фильтрация: поиск по имени, IP-адресу, операционной системе.
  - Быстрые кнопки: «Выбрать все», «Только в сети».
- **Отслеживание в реальном времени**:
  - Live-мониторинг прогресса передачи по каждому компьютеру (% и байты / общий объём).
  - Отображение текущей скорости передачи данных (КБ/с, МБ/с).
  - Сводные счётчики: *Всего*, *В процессе*, *Успешно*, *Ошибки*.
  - Общий шкальный индикатор выполнения всей задачи.
- **Умное управление файлами и путями**:
  - Drag-and-Drop загрузка файлов в веб-интерфейсе.
  - Автоматическое создание родительских каталогов на удалённом клиенте (`mkdir -p` / `New-Item -Force`).
  - Умные пути по умолчанию: `C:\Temp\<имя файла>` для Windows и `/tmp/<имя файла>` для Linux/macOS.
  - Опция перезаписи существующего файла.
- **Опциональный запуск после передачи**:
  - Возможность автоматически запустить файл сразу после успешной загрузки (поддерживаются `.exe`, `.msi`, `.bat`, `.ps1`, `.sh` и т.д.).
  - Передача аргументов запуска (тихая установка: `/quiet`, `/qn`, `--silent` и др.).
  - Отслеживание кода завершения процесса (Exit Code).
- **Отказоустойчивость и безопасность**:
  - Каждая загрузка защищена уникальным одноразовым криптографическим токеном.
  - Корректная работа через самоподписанные HTTPS-сертификаты MeshCentral.
  - Встроенный тайм-аут-вотчдог (Watchdog) для выявления зависших или отключившихся клиентов.
  - Кнопка **«Повторить неудачные»** для перезапуска передачи только на тех компьютерах, где произошёл сбой или которые были выключены.
- **История операций**:
  - Сохранение истории всех предыдущих отправок (дата, имя файла, размер, успешные/неудачные узлы, детальный лог).
- **Нулевые внешние зависимости**:
  - Плагин написан исключительно на встроенных модулях Node.js (`fs`, `path`, `crypto`). Не требует `npm install` сторонних пакетов.

## 🚀 Установка плагина

### Шаг 1. Включение поддержки плагинов в MeshCentral
Если у вас ещё не включены плагины в MeshCentral, откройте конфигурационный файл сервера (обычно `meshcentral-data/config.json`) и добавьте блок `"plugins"` внутри `"settings"`:

```json
{
  "settings": {
    "plugins": {
      "enabled": true
    }
  }
}
```
> **Важно**: После изменения `config.json` перезапустите службу MeshCentral (`systemctl restart meshcentral` или перезапуск Node.js процесса).

---

### Шаг 2. Размещение файлов плагина

#### Вариант А: Ручная установка (самый простой способ)
1. Скопируйте папку `meshcentral-multideploy` на сервер MeshCentral в каталог плагинов:
   ```text
   meshcentral-data/plugins/multideploy/
   ```
2. Убедитесь, что внутри лежат файлы:
   ```text
   meshcentral-data/plugins/multideploy/
   ├── config.json
   ├── multideploy.js
   ├── package.json
   └── changelog.md
   ```
3. Перезапустите сервер MeshCentral. Плагин автоматически активируется.

#### Вариант Б: Установка через веб-интерфейс MeshCentral
1. Войдите в MeshCentral под учётной записью администратора сайта.
2. Перейдите в раздел **My Server** (Мой сервер) ➔ вкладка **Plugins** (Плагины).
3. Нажмите кнопку **Download Plugin** (Загрузить плагин).
4. Вставьте прямую ссылку на `config.json` вашего репозитория:
   ```text
   https://raw.githubusercontent.com/Sokol549/MeshCentral-MultiDeploy/master/config.json
   ```
5. Нажмите **OK** и перезагрузите сервер при появлении запроса.

## 🖥️ Использование

### 1. Открытие мастера отправки
После установки плагина в веб-интерфейсе MeshCentral появится кнопка:
- **«📤 Массовая отправка файлов»** в панели инструментов устройств (сверху).
- Также в свойствах любого устройства появится отдельная вкладка **«Отправка файлов»**.

### 2. Пошаговый процесс:
1. **Шаг 1: Выбор компьютеров**
   - Выберите группу устройств (Mesh) из выпадающего списка или оставьте «Все группы».
   - Используйте фильтр «Только в сети», чтобы исключить оффлайн-машины, либо отметьте нужные компьютеры вручную.
2. **Шаг 2: Выбор файла**
   - Перетащите файл в зону загрузки (Drag & Drop) или кликните для выбора.
   - Файл мгновенно загружается на сервер с вычислением SHA256 хеша.
3. **Шаг 3: Настройка параметров**
   - **Путь назначения**: Укажите путь (например, `C:\Distr\` или `/opt/apps/`). Если оставить пустым, файл запишется в стандартную временную папку (`C:\Temp\` или `/tmp/`).
   - **Перезаписывать**: По умолчанию включено.
   - **Запустить файл после загрузки**: При необходимости активируйте чекбокс и укажите ключи командной строки (например, `/S` или `/qn`).
4. **Шаг 4: Запуск и мониторинг**
   - Нажмите зелёную кнопку **«🚀 Начать отправку»**.
   - Интерфейс автоматически переключится на вкладку **«Отслеживание»**, где в реальном времени будут отображаться:
     - Прогресс скачивания по каждому клиенту (в байтах и процентах).
     - Скорость скачивания в реальном времени.
     - Статусы: `⏳ В очереди`, `🚀 Загрузка`, `✅ Завершено`, `❌ Ошибка`.
     - Результат запуска файла (код выхода процесса).

### 3. Повтор неудачных устройств
Если часть компьютеров была выключена или произошла ошибка записи:
- На вкладке отслеживания появится кнопка **«🔁 Повторить неудачные»**.
- Нажмите её, чтобы отправить файл повторно только на те компьютеры, где статус был ошибочным.

### 4. Просмотр истории
- На вкладке **«История отправок»** хранится журнал всех предыдущих задач с детализацией по каждому компьютеру.

## 🔒 Безопасность

1. **Авторизация**: Доступ к API загрузки и запуска имеют только авторизованные администраторы MeshCentral.
2. **Одноразовые токены**: Для каждого целевого компьютера создаётся свой секретный временный токен скачивания. Доступ к скачиванию файла по прямой ссылке без токена заблокирован.
3. **Изоляция хранилища**: Загруженные файлы хранятся в защищённой директории `meshcentral-data/multideploy/files`.
